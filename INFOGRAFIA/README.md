# Mi ruta hacia la libertad: infografía

Infografía física de apoyo a la página web. Tamaño A4 vertical (794 x 1123 px), con la misma paleta del sitio: azul marino, bronce y borgoña, con detalles en rosa pálido.

## Estructura

```
infografia/
├── infografia.html      Contenido (cinco bloques)
├── css/
│   └── infografia.css   Estilos y configuración de impresión
└── README.md
```

## Cómo imprimirla o exportarla a PDF

1. Abra `infografia.html` en Chrome o Edge.
2. Imprima (Ctrl+P) y elija "Guardar como PDF" o su impresora.
3. Tamaño de papel: A4. Márgenes: Ninguno. Active "Gráficos de fondo".
4. Si imprimirá en tamaño carta, elija "Ajustar a la página".

## Código QR

El recuadro de la esquina inferior derecha es un espacio reservado. Cuando la página esté publicada, genere el QR con su dirección web, guárdelo como `qr.png` en esta carpeta y reemplace el recuadro `<div class="qr-slot">` por:

```html
<div class="qr-slot"><img src="qr.png" alt="Código QR de la página web"></div>
```
